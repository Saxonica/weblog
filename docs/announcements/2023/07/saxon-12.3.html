Announcing Saxon 12.3 Announcing Saxon 12.3! The Saxon 12.3 maintenance release has been published. This is a maintenance release for Java, C#, C/C++, PHP, and Python that fixes a number of issues reported since the Saxon 12.2 release. Saxon 12.3 was released on 4 July 2023. This release has been uploaded to the usual locations on the Saxonica website, GitHub, and Maven, PyPi, and NuGet. SaxonCS 12.3 is built with .NET 6. This release includes SaxonC and Python releases for the ARM 64 architecture as well as X86-64 architecture. For a list of the issues resolved in this release, please visit the issue trackers for SaxonJ and SaxonCS or SaxonC on the Saxon support site. Download products: Binaries for PE and EE are available from our download pages. SaxonJ-HE is available on the Maven Central repository. SaxonJ-HE, PE, and EE can also be found on our experimental Maven repository. Python wheels for SaxonC (HE, PE, and EE) are available from PyPI. SaxonCS is available on NuGet Saxon-HE is no longer distributed on SourceForge. It is now available from our open source GitHub repository. The GitHub repository also provides source code for those who need it. For more details, please consult the documentation.
