By Matt Patterson on November 19, 2026 at 02:50p.m.

A new security vulnerability (CVE-2026-114938) has been announced against OpenJDK. The vulnerability exists in the JDK’s implementation of the Base 64 decoder when running on affected x86-64 hardware. Some code within Saxon and its dependencies will make use of the JDK’s Base 64 decoder. User applications may also do so. Customers using SaxonJ on affected x86-64 hardware should upgrade their Java version as soon as possible.

The vulnerability exploits code which can only run on a CPU that supports AVX-512 instructions. SaxonJ is only vulnerable if running on a vulnerable version of Java on an AVX-512 capable CPU (typically a high-end server CPU).

SaxonC is not vulnerable. SaxonC for x86-64 on Linux, macOS, and Windows, is compiled to support a wide range of CPUs, and excludes AVX-512 support at compile time as part of that effort.
